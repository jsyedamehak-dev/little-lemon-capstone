
# Little Lemon Table Booking App

## Project Description

Little Lemon is a responsive restaurant table booking application built with React. It allows users to select a booking date, time, number of guests, and occasion.

## Features

- Responsive booking form
- Date selection and validation
- Available time selection
- Guest selection from 1 to 10
- Occasion selection
- Accessible form labels
- Booking confirmation screen
- Option to make another booking
- Error messages for invalid dates
- Automated tests using React Testing Library

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Jest
- React Testing Library

## Installation

1. Install Node.js and npm.
2. Clone or download this repository.
3. Open the project folder in the terminal.
4. Install dependencies:

   npm install

5. Start the application:

   npm start

## Run Tests

Run the following command:

    npm test -- --watchAll=false

## Important Note

This project demonstrates the frontend booking experience. It does not connect to a real restaurant booking system or database.
